# Resources

Reference papers and language code tables used in this project.

- `iso-639-3.tab` — ISO 639-3 language code registry (ID, scope, type, reference name)
- `2111.09296.pdf` — Babu et al. 2021, XLS-R: self-supervised cross-lingual speech representation learning at scale
- `mls.pdf` — Pratap et al. 2020, MLS: a large-scale multilingual dataset for speech research
- `vl107.pdf` — Valk & Alumäe 2020, VoxLingua107: a dataset for spoken language recognition
- `voxpopuli.pdf` — Wang et al. 2021, VoxPopuli: a large-scale multilingual speech corpus
